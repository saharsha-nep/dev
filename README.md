# Gardening Tools Store
A responsive front-end e-commerce website for selling gardening tools and supplies, developed using **HTML, CSS, and JavaScript**. The project demonstrates responsive web design principles, intuitive navigation, and a clean user interface for browsing products.

## Features
* Responsive layout for desktop and mobile devices
* Product catalog organized into clear categories
* Clean and intuitive user interface
* Simple navigation for an improved user experience
* Built using semantic HTML, custom CSS, and JavaScript
